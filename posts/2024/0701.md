## 1、Express

> 高度包容、快速而极简的 Node.js Web 框架

- 1、安装

```bash
npm install express --save
```

> 导入 express 创建 web 服务器

```js
const express = requre('express')
const app = express()
```

- 2、获取 URL 中携带的查询参数

> 通过 req.query 对象，可以访问到客户端通过查询字符串的形式，发送到服务端到参数

```js
console.log('req.query')
```

- 3、获取 URL 中的动态参数

> 通过 req.params 对象，可以访问到 URL 中，通过:匹配到的动态参数

```js
console.log('req.params')
```

- 4、托管静态资源

```js
app.use(express.static('public'))
```

> 通过上面的代码就可以将public目录下的图片、css文件、js文件对外开放访问了。
> 如：<http://127.0.0.1/images/nvshen.jpg>

- 5、挂载路径前缀

```js
app.use('public', express.static('public'))
```

> 现在就可以通过带有/public前缀地址来访问public目录中的文件了。
> 如：<http://127.0.0.1/public/css/style.css>

## 3、Express 模块化路由

> **1、调用 express.Router()函数创建路由对象挂载具体路由**

```js
// 导入 express
const express = require('express')

// 创建路由对象
const router = express.Router()
```

```js
// 挂载具体的路由

// GET
router.get('/get', (req, res) => {
  // 获取客户端通过查询字符串，发送到服务器的数据
  const query = req.query
  res.send({
    status: 0,
    success: true,
    data: query,
    message: `Get ${req.url} success. 请求到达服务器的时间是：${req.startTime}`
  })
})

// POST
router.post('/post', (req, res) => {
  // 获取客户端通过请求体，发送到服务器的 URL-encoded 数据
  const body = req.body
  res.send({
    status: 0,
    success: true,
    data: body,
    message: `POST ${req.url} success. 请求到达服务器的时间是：${req.startTime}`
  })
})
```

> **使用 module.exports()函数向外共享路由对象**

```js
// 向外共享路由对象
module.exports = router
```

> **2、使用 app.use()函数注册路由模块**

```js
// 导入路由模块
const router = require('./router')

// 注册路由模块
app.use('/api', router)
```

## 4、Express 中间件

> ‌Express 中间件就是处理请求的函数‌，它能访问请求和响应对象，在请求和响应之间做额外处理，整个 Express 应用本质上就是一系列中间件函数的调用。‌‌‌

- 1、全局中间件

> 能访问请求和响应对象‌：中间件函数可以拿到 req 和 res 对象，对它们进行修改或操作。

> 决定是否继续传递‌：调用 next() 就把控制权交给下一个中间件，不调用则结束请求响应循环。

```js
// 全局生效的中间件
app.use((req, res, next) => {
  // 获取请求到达服务器的时间
  req.startTime = Date.now()
  console.log(
    `收到 ${req.method} 请求，路径是 ${req.url}，请求到达服务器的时间是：${req.startTime}`
  )
  // 继续向后匹配路由
  next()
})
```

- 2、错误中间件

> 可以做各种事情‌：执行任意代码、记录日志、解析请求体、验证权限、处理错误等等。‌‌‌

```js
// 挂载错误的路由
router.get('/password', (req, res) => {
  throw new Error('服务器内部发生了错误，获取用户密码失败！')
  res.send({
    status: 1,
    success: false,
    data: null,
    message: `Get ${req.url} failed. 请求到达服务器的时间是：${req.startTime}`
  })
})

// 全局生效的错误处理中间件
app.use((err, req, res, next) => {
  console.log('发生了错误：' + err.message)
  res.send('Error: ' + err.message)
})
```

- 3、内置中间件

> 1、express.static() 用于托管静态文件，如HTML文件、图片等。

```js
app.use('public', express.static('public'))
```

> 2、express.json() 用于解析JSON格式的请求体。GET

```js
app.use(express.json())
```

> 3、express.urlencoded() 用于解析URL编码的请求体。POST

```js
app.use(express.urlencoded({ extended: true }))
```

## 6、JSONP 接口

> 采用 JSON 格式进行数据传输的应用程序编程接口，常用于前后端交互 。‌‌‌

```js
// 必须在配置 cors 中间件之前，配置 JSONP 的接口
app.get('/api/jsonp', (req, res) => {
  // 得到发送到服务器的回调函数的名称
  const funName = req.query.callback
  // 拼接一个合法的 JS 脚本代码，调用客户端的回调函数，并把数据作为实参传递给客户端的回调函数
  const scriptStr = `${funName}(${JSON.stringify({
    status: 0,
    success: true,
    data: {
      name: '刘六',
      age: 24
    },
    message: `Get ${req.url} success. 请求到达服务器的时间是：${req.startTime}`
  })})`
  // 把拼接好的 JS 脚本代码响应给客户端浏览器执行
  res.send(scriptStr)
})
`})
```
